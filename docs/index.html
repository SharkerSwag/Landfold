第一篇 / 山地与人居

一面山坡，
不止一层风景。

第一眼，是山的轮廓。
再看，是水的光泽。
目光停留得更久一些，
便看见生活的形状。

READ THE LAND, SLOWLY.
01

山水之间，
有人生活。

从远处望去，田埂像山坡上的细密笔触。把视线抬高，林地与村落也进入画面。一张照片，开始有了比风景更深的层次。

在红河哈尼梯田的区域系统中，村寨位于山顶森林与梯田之间，沟渠将水引向耕地。理解这片地景，需要把这些联系一起读进去。[1]

FOREST / 山顶森林

水的故事，
从山林开始。

区域资料将山顶森林与水源联系起来。水经沟渠输送到坡面上的梯田，森林因而是理解农田系统的一部分。

试着想一想：田里的水，与田地之外的哪些地方有关？
